3.1 Algorithm

We tweak the algorithm from FlashAttention to reduce the number of non-matmul FLOPs. This is because modern GPUs have specialized compute units (e.g., Tensor Cores on Nvidia GPUs) that make matmul much faster.

Algorithm 1 FlashAttention-2 forward pass
1: Divide Q into Tr blocks of size Br × d each, and divide K, V into Tc blocks…
2: for 1 ≤ i ≤ Tr do
3:   Load Qi from HBM to on-chip SRAM. Initialise Oi = 0, ℓi = 0, mi = −∞.
4:   for 1 ≤ j ≤ Tc do
5:     Compute Si(j) = QiKjT.
6:     Compute mi(j) = max(mi(j−1), rowmax(Si(j))) …
7:     Compute Oi(j) = diag(em(j−1)−m(j)) Oi(j−1) + P̃i(j)Vj.
8:   end for
9:   Compute Oi = diag(ℓi(Tc))−1 Oi(Tc).
