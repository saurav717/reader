The workflow, end to end

Every step starts from R, and comes back to it

Home is the hub; each stage is one keystroke or one click from it, and each stage hands you on to the next instead of dropping you back in a list.

FindOne box for search, links and PDFs; the map shows what's missing.
TriageNew papers arrive with a reason and get sorted from the keyboard.
PlanA project or today's plan picks what's next, so you don't have to.
ReadResume at the exact spot; hover R to hop between papers.
Wrap upAt 100%: three takeaways, file it, open the next paper.
Review & writeOld highlights resurface; highlights become cited paragraphs.
