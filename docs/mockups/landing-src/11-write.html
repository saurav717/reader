Related work — operator learning near discontinuities

Draft ✦Export .tex / .bib

Neural operators learn maps between function spaces rather than between fixed discretisations. The Fourier Neural Operator parameterises the kernel integral in Fourier space and is discretisation-invariant, allowing zero-shot super-resolution [Li 2021].

That same mode truncation, however, smooths sharp fronts, and Gibbs-type oscillations appear near shocks [Chen 2026].

Drop to cite: “local kernels recover the differential operator as a limit” → [Liu-Schiaffini 2024]

Whether the error near a shock stays bounded as resolution grows is, to our knowledge, open…
