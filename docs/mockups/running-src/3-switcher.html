FlashAttention-2: Faster Attention with Better Parallelism and Work Partitioning

We tweak the algorithm from FlashAttention to reduce the number of non-matmul FLOPs. This is important because modern GPUs have specialized compute units that make matmul much faster.

The online softmax trick can be rewritten so that we do not rescale both terms of the output update every iteration. Instead we keep an un-scaled version of the output and only scale it once at the very end of the loop.

We also do not have to save both the max and the sum of exponentials for the backward pass. We only need to store the logsumexp.
