Automatic Generation of High-Performance RL Environments

Writing a fast simulator by hand takes weeks. We show that an agent can translate a reference environment into a vectorised JAX implementation, verify it against the original step-by-step, and reach a 40× throughput gain on a single GPU.

§4.2 — We measure steps per second for 1M-step rollouts with batch size 4096, averaging over five seeds. Returns agree with the reference implementation to within 0.3%.

Our pipeline has three stages: translation, differential testing against the reference, and profiling-guided rewriting of the hot loop. Each stage is checked before the next begins.
