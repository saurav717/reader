Auxiliary-Loss-Free Load Balancing Strategy for Mixture-of-Experts· Wang et al. 2024 · arXivp. 4 / 18
3.1 Loss-Free Balancing

Before the top-K routing decision, we add an expert-wise bias bi to the original routing score of each expert. The bias is used only for selecting experts; the gating value that multiplies the expert output is still the original score, so the auxiliary term introduces no gradient into the language-modelling objective.

After each training step, we update bi according to the load of expert i in the batch: if an expert is over-loaded, its bias is decreased by a fixed step; if under-loaded, increased. The step size is a hyperparameter that trades the speed of balancing against the stability of routing.

3.2 Comparison with auxiliary-loss methods

Auxiliary-loss methods add a term to the loss whose weight α must be tuned. A small α leaves experts collapsing; a large α interferes with the primary objective. Loss-free balancing removes this trade-off: the routing score is never a function of the balance.
